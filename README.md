# repo-polish

**Point any AI coding agent at this repo and it will maintain one of your projects for you:** remove leaked secrets,
get it running on today's dependencies, record a demo GIF from a real run, design animated README visuals,
write an honest README, and hand it all back as a pull request.

No install, no SaaS. The whole method lives here as plain instructions (`AGENTS.md` + `playbook/`) and a few small tools.

## Use it

Open your AI agent (Claude Code, Codex, Cursor, Copilot agent mode, Gemini CLI, …) and say:

```text
Follow https://github.com/<you>/repo-polish/blob/main/AGENTS.md to maintain my project https://github.com/<you>/<project>.
```

The agent reads `AGENTS.md`, works through the playbook, asks you only for what it can't find (like API keys to run
the app), and ends with a pull request plus a short report: what changed, what was verified, which secrets to rotate.

**Chat-only assistants** (no shell) work too, in *advisor* mode: they read your code and hand you the README,
the card config and the exact commands to run yourself.

## What it does

| # | Stage | What happens |
|---|---|---|
| 1 | Intake | clone, branch, check whether a live deploy still responds |
| 2 | Secrets | scan files **and git history**; move secrets to env vars; list what you must rotate |
| 3 | Understand | read the code (not just the existing docs) for architecture, main flow and real design decisions |
| 4 | Hygiene | untrack committed virtualenvs, build output, logs |
| 5 | Run it | pin drifted dependencies, replace retired APIs, fix crashes on the main path, verify output is *correct* |
| 6 | Demo | script the app with Playwright → optimised GIF (fast-forwards AI waits, hides animation noise) |
| 7 | Cards | animated light/dark SVG cards: hero, architecture, flow, capabilities, decisions, stack, terminal, code editor |
| 8 | Docs | a `docs/` folder for contributors: architecture, codebase map, setup + env vars, API, data, operations — flows drawn with [Archify](https://github.com/tt-a1i/archify) (asks you first) |
| 9 | README | from a template: demo first, then how it works, copyable run commands, honest "what's next" |
| 10 | Review | every claim checked against code, every card, diagram and GIF frame looked at |
| 11 | Ship | pull request — never a push to your default branch; asks how you want local files cleaned up |

Have many projects? [`playbook/12-many-projects.md`](playbook/12-many-projects.md) covers triage and doing one per session from a queue.

## Run the tools yourself

```bash
git clone https://github.com/<you>/repo-polish && cd repo-polish
npm install && npx playwright install chromium     # GIFs + screenshots (also needs ffmpeg)
```

```bash
# masked secret scan of a repo, including git history
tools/scan/secrets.sh ../my-project
```

```bash
# README cards from a config (copy templates/cards.example.json first)
uv run --with fonttools --with brotli python tools/cards/cards.py ../my-project/docs/assets/cards.json ../my-project/docs/assets
```

```bash
# demo GIF from a scripted run (see templates/steps.example.json)
W=1440 H=900 GW=760 node tools/gif/record.mjs http://localhost:3000 steps.json ../my-project/docs/demo.gif
```

## Principles the agent follows

- **Pull requests only**, and it asks before anything outward-facing.
- **Never prints or commits a secret**; tells you which ones to rotate.
- **Every claim in the README must be true of the code.** No invented features or metrics.
- **Fix what blocks running, safety or docs** — nothing more. Other issues go in "What's next".
- **Looks at what it makes** before calling it done.
- **No AI attribution** — no AI co-author trailers or "generated with" lines. You are the author.

## Repo layout

```
AGENTS.md            the contract every agent reads first (CLAUDE.md points here)
playbook/            one file per stage, with commands and "done when" checks
templates/           README, docs/ pages, cards config, GIF script, PR body, end-of-run report
tools/scan/          secrets.sh
tools/cards/         cards.py (+ embedded-font helper, cached icons)
tools/gif/           record.mjs (GIF), shot.mjs (screenshots)
examples/nlp-sql/    a complete real run: config, script, cards, GIF
```
